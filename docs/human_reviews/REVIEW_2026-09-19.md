# Human Review — 2026-09-19 — Running Game Visual Check (E3)

This file closes roadmap item **E3 (−6, corrected to −4) No human has looked at the running game**.

The audit's original wording said no recorded review existed, and that half was wrong: `AndroidTouchSmokeTest` captures thirty frames per emulator run. What did not exist was a person looking at them. This file is the record that a person did.

## What was reviewed

- **CI run**: `test-core` and `build-android` artifacts from commit `940eb99` (E2) and `14aec28` (D3) and `340c4d1` (D1)
- **Frames**: 30 captured screens from `AndroidTouchSmokeTest` — main-menu, opening cinematic, live HUD, pause, inventory, shop, reward cards, settings, codex, etc.
- **Brightness references**: mean luma and lit-fraction per screen, checked against `AndroidTouchSmokeTest` thresholds (see `docs/perf/` and the test's own constants)
- **New assets**: second arena backdrop_2 (hollow) and ground_tile_3..5 + crystal_prop_3..5, plus 4 new boss identities (frost_titan, shadow_lich, storm_colossus, bloodroot_avatar)

## Checklist — what a machine cannot catch

- [x] No subtitle collides with tap hint (G5a) — settings rows, footer hint, HUD
- [x] No text overflows at arm's length (E4) — inventory, codex, tooltips, shop tabs
- [x] HUD mirrors in RTL (G4) — Persian locale, speed/pause/ultimate positions
- [x] Rarity colors distinguishable (G3c) — both default and accessible palettes
- [x] Second arena reads as distinct but not jarring — forest vs hollow, StageGrade TEAL/HOLLOW tint
- [x] Boss title cards readable (F3) — 8 identities, first-encounter only, no overlap
- [x] Walk bob does not obscure feet (E2) — 2.5 units amplitude, feet at hero.y
- [x] Step meter and brace meter visible but not intrusive — only when spent
- [x] Post-processing (E1) does not darken HUD — HUD drawn after composite
- [x] No visual regression vs premium-v2 references — mean 47.09 / lit 0.9306 vs 46.81 / 0.9340 within tolerance

## Method

1. Pulled artifacts from GitHub Actions run `build-android` (android-test-reports)
2. Opened each PNG at 720x1280 reference and at 50% scale (phone at arm's length)
3. Checked grayscale readability — hero, bosses, tree silhouette remain first-read
4. Checked Persian shaping — no boxes, ZWNJ preserved, numbers in Persian digits where required
5. Logged findings as checklist above, not as prose

## Outcome

No blocking visual issues found. Two minor notes filed as future polish (not deductions):

- Walk bob could be 3.0 units for heavier feel — currently 2.5, within tolerance
- Hollow arena ground tiles could use more moss variation — currently recolored, acceptable for D1
