# Independent re-audit — 737 / 920 in scope, commit `12e4dc0`, 2026-09-17

This is the 2026-09-16 audit run again on the finished round. Same rubric, same weights, same rule that no
category passes on prose — and this time every figure below is produced by a tool committed beside it rather
than transcribed from a conversation. The previous audit scored **550 / 1,000**, of which **505** was in scope;
this one measures **737 of the 920 in-scope points**. The release-preparation category (80 points) stays out of
scope by owner direction, so this round has no 1,000-point figure at all: 737 of 920 in scope is the whole
statement, and it is the same nine categories the first audit scored 505 in.

**Gate 1 is not met.** The roadmap asks for ≥ 900 of 920 at Phase 97; the round measures 737. The 183-point gap
is itemised sub-item by sub-item in this document, and it is concentrated in four places: the hero cannot be
moved, Persian and right-to-left support does not exist, three of the six onboarding/localisation items are
deferred, and nothing ships compressed. None of those is hidden — they are the open items of the roadmap — but
a gate that is not met has to be written as not met.

## Method

- The ten categories and their weights are the 2026-09-16 audit's, unchanged: 150 / 150 / 120 / 80 / 130 / 50 /
  100 / 80 / 60 in scope, 80 out (release preparation).
- Every category is scored from a list of sub-items, each with its own weight, a verdict, and the measurement
  the verdict is about. The arithmetic is in the tables; nothing is scored from an impression.
- `tools/audit/measure_round.py` (committed with this audit) reads the tree, the JUnit XML a real test run
  leaves behind, the asset manifest, the hash ledger, the roadmap and the filed performance runs. Its output is
  frozen beside this document as `MEASUREMENTS_2026-09-17.json`, so the numbers can be re-taken and diffed.
- A real `:core:test` in this environment (JDK 17): **179 classes, 720 tests, 0 failures, 0 errors, 0 skipped,
  36.8 s**. The python suites: **tools/blender 64, tools/visual 54, tools/texture 25, tools/perf 20**.
- Gates re-run rather than quoted: `validate_generated_assets.py` (111 assets, 157 RGBA PNGs, 518,959,104
  decoded bytes, max page 4096, *measured gates 8 / config-presence checks 3*), `validate_material_maps.py
  --check` (39 maps re-derived), `compose_master_tier.py --check` and `create_master_tier_review.py --check`.
- CI runs were harvested including the red ones. Named in the categories below: run `35212458225` (job
  `105173001244`) passed the stage-grade pair and failed the compressed-texture comparison; run `35212458179`
  failed the composed-tier check inside `git show` because the job checked out a single commit; and both
  workflows are **green** for this audit's commit — core `35213390487`, Android `35213390481`.
- **Not reviewed, and therefore neither credited nor deducted:** playing the game by hand (touch feel, long-run
  fun), running the APK on a physical device, judged audio quality, and whether the current art direction reads
  as 2026-standard to a human eye. The first audit left the same four out.

## What changed since 2026-09-16

- **The finding that dominated the last audit is reversed and guarded.** No sheet ships a resampled copy, and
  the gate that would catch a return of the 2× NEAREST batch fails on its own fixtures.
- **The tests that were disabled are back, and a scanner keeps them back.** 517 tests became 720; vacuous
  assertions, disabled tests and `|| true` gates are build failures now, with a negative control.
- **The runtime tier ships the render's own pixels** for the eight sheets a provenance measurement classifies
  as independent renders, with the memory arithmetic in the manifest and a review that binds each sheet by hash.
- **Memory became arithmetic.** The catalog, the live combat set, the wave-50 process, the cold start and the
  APK are all budgeted, measured on device, and gated; every published number traces to a filed run.
- **The art gained a paper trail**: 39 PBR maps, a hash ledger over 157 PNGs, per-batch reviews, and 0 borrowed
  assets.
- **Integrity work that shows up as honesty**: the 2026-09-16 audit stayed in the repository, two withdrawn
  documents say they are withdrawn, and the roadmap lists 55 open items instead of claiming a score.
