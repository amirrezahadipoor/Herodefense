# Independent re-audit — 722 / 920 in scope, commit `12e4dc0`, 2026-09-17

This is the same rubric as [`AUDIT_2026-09-16.md`](AUDIT_2026-09-16.md), re-run over the round that answered
it. The first audit scored this repository **550 / 1000**, of which **505** was in scope; this one measures
**722** of the same **920** in-scope points. Release preparation — the tenth category, 80 points — is out of
scope at the owner's direction, so nothing in this document adds up to 1000, and this audit does not claim a
1000-point score for the project.

**Gate 1 is not met.** The roadmap asks for ≥ 900 of 920 at Phase 97. The gap is 198 points, and this document
itemises every one of them in plain language, sub-item by sub-item, with the measurement each verdict is about.
The four largest are not surprises: the hero still cannot be moved during a wave, Persian and right-to-left
support does not exist, 200 waves carry four boss identities, and the compression the repository built is not
allowed to ship by its own quality bar.

## Method

- Ten categories, the first audit's weights, unchanged: 150 / 150 / 120 / 80 / 130 / 50 / 100 / 80 / 60 in
  scope plus 80 out of scope.
- Every category is scored from sub-items. Each sub-item carries a weight, a verdict and the number behind it;
  the weights inside a category add to its weight, so the arithmetic is checkable.
- Nothing is scored from a claim. The numbers below come from this tree, and where a number is a judgement
  rather than a measurement, the row says so.
- Not reviewed, and therefore neither credited nor deducted: playing the game by hand (touch feel, long-run
  fun), running the APK on a physical device, judged audio quality, and whether the current art direction
  reads as 2026-standard to a human eye. The first audit left the same four out.

## The five deductions that cost the most, in plain language

1. **Persian and RTL do not exist (−47 without them).** The game's text is English-only and laid out
   left-to-right, in a project whose roadmap names Iran as the market; Persian is 25 points of that, the
   unhandled Back button 10, accessibility beyond haptics 7 and the store surface 5. The work is understood and
   deferred by the owner, which costs the same points as forgetting it would.
2. **The hero cannot be moved (−18 in gameplay).** Every wave the player aims, times abilities and picks targets,
   but never chooses a position. That is one fewer decision than the genre assumes, and it is the oldest open
   finding in this repository.
3. **Audio is a spine, not a soundtrack (−17).** 4 tracks and 20 effects for 200 waves, eight creature families
   and twenty boss encounters.
4. **The optimiser is still ahead of the player it is tuned for (−11 of the balance category's 18).** It ends
   every run at 200 waves where the non-optimiser's run ends at a mean of 69.7, and the ascension ladder is
   inverted for the latter.
5. **Nothing ships compressed (−11 in size).** The encoder, the container, the per-device policy, the
   projections and a device proof all exist; the encoder's quality bar is 32 dB, it measures 28.88 dB, and the
   tool correctly refuses to ship. Honest — and still a deduction, because the memory the compression would buy
   is the memory the next content batch needs.

## What is not covered by this score

- Playing the game. Touch feel, difficulty *felt* over a session, and whether the 200-wave arc stays interesting
  are not measurable by this repository's tools today.
- A physical device. Every device number here comes from an emulator.
- Audio and art quality as a human perceives them.
- Release preparation: versioning, signing, store listing, minification and the release pipeline — 80 points,
  excluded by the owner.

## How to re-measure

```bash
./scripts/gradle.sh :core:test        # 720 tests, JUnit XML under core/build/test-results
./scripts/gradle.sh :core:balanceGate # the curve, the band, the tiers, the trials
python3 -m unittest discover -s tools/visual/tests   # asset gates and their negative controls

python3 tools/perf/check_perf_provenance.py          # every documented number has to be a filed run
python3 tools/audio/check_audio_levels.py --check
```

The score itself is a judgement: this document's own weights and verdicts, printed row by row so that a reader
can disagree with any single row and see what it costs.
